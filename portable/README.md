# iCourse Player

双击 **启动播放器.vbs**，在默认浏览器中打开课程库。

默认读取 `D:\Videos`，可以在播放器右上角“设置”中修改视频目录。
支持视频播放、逐句字幕、PPT 时间联动、课件放大、倍速、画中画、自动连播和继续学习。

学习进度与播放偏好保存在浏览器中。沿用 `http://127.0.0.1:8765/`，使用原来的浏览器即可继续读取已有进度。

关闭浏览器后，播放服务继续在后台等待。双击 **停止播放器.vbs** 可退出后台服务。

本目录包含独立 Python 运行时，移动整个目录后仍可启动，无需原项目或另装 Python。
视频、课件和字幕仍在视频目录中，本目录只保存程序、设置和运行日志。
下载、转存及字幕生成由 ROG 和云端部署负责，新资料到达视频目录后会自动出现在课程库中。

文件说明：`settings.json` 为视频目录和端口设置；`data` 为运行日志；`runtime` 为 Python 运行时；`app` 为播放器程序和页面。
